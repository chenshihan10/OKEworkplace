# 第9步：学习策略优化梳理

日期：2026-11-27
范围：基于当前代码与 `backend/data/signals.db` 的实际数据，梳理「还能怎么优化」。
约束：本文只做梳理，不含实现代码；不涉及评分权重与判断逻辑的改动。

---

## 0. 结论先说

1. 当前系统**没有在线学习**。评分是规则加权（`market_score.py`），`DirectionTracker` 只做方向稳定，没有任何权重会随样本自动更新。"学不好"这个前提不成立，真正的问题是**评估数据不干净 + 毛收益接近 0**。
2. 最该先做的不是"换学习算法"，而是**把评估口径修对**（已完成的预测去重只是第一步）。
3. 影子评分目前**没有信息量**：248 条记录中，影子与正式的分数差 100% 等于 OI 分项差（`official_oi≈7`，`shadow_oi≈0~2`），它测的不是"另一套模型"，而是"少了 OI 分"。
4. 按现状，任何"调参/A-B/机器学习"结论都不可信；先攒够**独立样本**，再谈优化。

## 2. 三类划分

### A. 现在就能做（不依赖更多样本，或只需极小样本）

| 项 | 需要什么数据 | 怎么验证有没有用 | 备注 |
|---|---|---|---|
| A1 评估口径固化 | 现有库即可 | 同一批结果下用 bootstrap 给出胜率/收益的 95% 置信区间；口径变更前后用**配对比较**（同一批预测） | 已做：K 线去重。还应固定「毛/净分离、分视界、分币种」 |
| A2 影子评分修复 | 现有 248 条 + 运行期 OI 采样 | 修复后差值分布不再等于 OI 差；同一时段内 official 与 shadow 的收益差是否显著 | 当前 gap 216/216 = OI 差，等于没做 A/B |
| A3 成本门槛可视化 | 现有 419 条结果 + 成本参数 | 按视界给出毛收益分位数与成本的差；30m/1h 毛收益中位数是否 > 成本 | 不改评分，只在评估/展示层标注"需要多少毛收益才不亏" |
| A4 品种池分层 | 现有数据 | 代币化股票与加密分开统计后，各池样本量与 CI；两池胜率差是否超出 CI | NVDA 曾占 68% 权重，混池结论会被单品种带偏 |
| A5 方向偏置与翻转监控 | 运行期即可 | 统计 LONG 占比、单位时间方向翻转次数、翻转后 1 根 K 线的实际收益 | 11-24 NVDA 15 分钟内翻转 251 次，属噪声翻转 |
| A6 写入异常监控 | 运行期即可 | 每根 K 线每币种条数 >1 告警；predictions 与 results 条数比恒为 1:3 | 这次 252 条的教训，靠监控而不是靠事后发现 |

### B. 需要再攒样本才可信

| 项 | 需要什么数据 | 怎么验证有没有用 | 大致样本门槛 |
|---|---|---|---|
| B1 市况（regime）分桶 | 预测时已写入 regime，持续累积 | 分桶胜率 + CI；把时间前后对半分，看结论是否稳定 | 每桶独立预测 ≥ 30（建议 100） |
| B2 多周期共振 / 订单流偏向分桶 | `prediction_context` 已有字段 | 桶间差异要大于桶内波动；walk-forward 验证 | 每桶 ≥ 30；当前 LONG 桶 1 条、SHORT 桶 4 条，均无意义 |
| B3 评分参数变体 A/B | 需要预注册变体，且每条预测打上变体标识 | 样本外对比；同一时间段内多变体并行 | 每变体 ≥ 200 条独立预测（按每币种 2 条/小时，约 4~5 天） |
| B4 波动率自适应阈值/成本 | 需按 ATR 分位分桶的样本 | 分桶后净收益是否改善；成本假设与实际滑点偏差 | 每个波动区间 ≥ 50 条 |
| B5 方向稳定器的边际价值 | 需要把 `raw_direction` 与 `direction` 一起落库 | 同一时刻"稳定前/稳定后"两组回验收益对比 | 现有库未存 raw_direction，需先补字段再攒 |

### C. 样本/数据根本不支持（不是"再攒几天"能解决）

| 项 | 为什么现在做不了 | 前置条件 |
|---|---|---|
| C1 监督学习 / 在线更新权重 | 预测表只存了方向、分数、理由，**没有预测时刻的完整特征向量**；样本 151 条且高度相关；FLAT 标签占比不低 | 先建特征快照（每次预测存全量特征），再谈模型；还需要严格步行前推与样本外验证 |
| C2 强化学习 / 自动调仓 | 无真实成交滑点分布、无订单簿历史、无资金曲线回放 | 需要真实或高保真模拟撮合数据 |
| C3 组合优化 / 跨品种对冲 | 7 天样本、币种相关性不稳定 | 至少数月跨品种数据 |
| C4 "OI 上升→方向更准"这类因果结论 | OI 只在运行期采样，15m 窗口覆盖不足 90% 时直接记 0，没有长期时间序列 | 需要持续的 OI/资金费率历史归档 |
| C5 承诺具体胜率目标（如 55%） | 当前毛收益中位数约 0，成本 0.14%/次；样本与成本模型都不支持 | 先证明存在毛边际，再谈胜率目标 |

## 3. 建议的执行顺序

1. **A1/A2/A6**（评估口径、影子评分、异常监控）——成本最低，直接决定后面所有结论可不可信。
2. **A4/A5**（分层与偏置监控）——让统计不再被单品种和方向偏置主导。
3. **B1/B2**——用现有预测节奏自然累积，约 2 周可让多数桶到达 30 条。
4. **B5 → B3**——先把 `raw_direction` 落库（只加字段，不改判断），再做参数 A/B。
5. **C1 前置准备**——特征快照这件事可以现在就开工（只存数据、不参与评分），否则半年后依然没有训练集。

## 4. 当前最大的陷阱

1. **把重复样本当独立样本**。这次清理就是活例：同一段行情重复 232 次，把真实胜率 33% 压成 24%，把 NVDA 的 39.7% 压成 20.7%。任何"调参提升"如果发生在重复样本上，都是假的。
2. **用同一批数据反复调参**。样本只有 151 条，试 20 组参数必然有一组"看起来很好"，这是纯过拟合。必须预注册 + 样本外。
3. **拿小分桶的极端比率下结论**。`SHORT` 共振桶 4 条预测、100% 胜率；`bearish` 订单流桶 2 条。这类数字没有统计意义。
4. **把成本问题误判成方向问题**。30m/1h 的毛收益中位数≈0，净收益必然为负；此时优化方向权重不会改善结果，只有"减少交易/拉长视界/降低成本"有意义。
5. **影子评分形同虚设却不自知**。差值恒等于 OI 分项差，说明它没有提供任何独立信息；不做 A2，就无法判断任何"新想法"是否更好。
6. **只看胜率不看赔率**。胜率 33% 若平均盈亏比足够高仍可盈利；当前平均净收益为负说明赔率也不够。评估必须同时看收益分布（分位数）、最大回撤式的连续亏损长度。
7. **时间跨度错觉**。7 天、单一市场状态（近期多数品种下行）下的结论，换一个月可能完全反转。
